# JetForge

参数化自定义喷气发动机。**画几何 → 算性能**：外形尺寸、压气机/燃烧室/涡轮/加力段的几何决定
推力、耗油率、涵道比、增压比与各转子转速，不是"填性能出曲线"。

安装、第一次上手、常见问题见包根的 `INSTALL.md`（`INSTALL.en.md` 是英文版）。

## 硬依赖

从第五阶段起，本 mod **硬依赖**下面两个：

| Mod | 用途 | 缺了会怎样 |
| --- | --- | --- |
| **Waterfall** | 尾焰（羽流、激波、热浪、色温全在它上面） | 没有尾焰。自绘尾焰在第五阶段已删，不会再退回。 |
| **RocketSoundEnhancement** | 干态发动机声音（多普勒、空气吸收、梳状滤波） | 干态声音只剩本 mod 自己那几层，不走 RSE 的处理链，听着"没毛边但也没空间感" |

两者都在 `GameData` 里装好后不需要再做任何配置：本 mod 的 `Waterfall.cfg` / `RSE.cfg`
会在检测到它们时自动挂上去（`NEEDS[...]`）。

缺依赖不会崩：零件照样能装、能算、能飞，`KSP.log` 里会有一行
`[JetForge] 缺少必需依赖：…`。

## 目录

```
GameData/JetForge/
  Parts/JetForgeEngine.cfg        发动机零件（内嵌一台默认双轴涡扇）
  Parts/JetForgeIntake.cfg        独立进气道零件（型线自己画）
  Localization/{zh-cn,en-us}.cfg  零件名与描述的两种语言
  Waterfall.cfg / WaterfallTemplates.cfg   羽流（9 个 FX，干/加力 × 冷/中/热）
  RSE.cfg                         RSE 声音组（组名 = engineID = JetForge）
  Sounds/                         9 层循环音源（由 RSE 的 JetsTurbines 派生，GPL-3.0）
  Textures/                       7 套贴图（冷/热/内壁/机匣/唇口/进气道内外）+ 法线
  UserDesigns/                    你自己存的设计（进游戏后才会出现）
  Plugins/JetForge.dll            插件本体
```

## 操作

VAB/SPH 里右键零件 → **JetForge 设计器**。页签从"总体"到"剖视"共 9 页：总体、风扇、
压气机、涡轮、燃烧室、加力、读数、热力图、剖视；简单模式只留 3 页（总体、读数、剖视）。
改完点"应用到零件"，质量、造价、外形、羽流、声音一起重算。

- **设计向导**：不知道从哪下手就点它——按用途/年代/飞行马赫挑一个预设起手，填目标推力，
  它反解叶尖直径与风扇压比并说明每个初值来自哪儿。改坏了能撤销（三步）。
- **测试台**（读数页）：海平面静推力、不同高度/马赫/油门的工况点、SFC 曲线。
- **进气道是独立零件**：它有自己的窗口（截面骨架 / 单截面轮廓 / 参数页）。
  迎角与侧滑由飞行状态实时算，不需要你填。
- **右侧栏"我的设计"** 把当前设计存成 `UserDesigns/<名字>.cfg`；同一型号的多个零件之间
  会自动同步（改了其中一台，装在一起的同款跟着改）。
- 界面有水/英文两种：游戏语言是中文就中文，否则英文。日志永远是中文。

## 已知取舍

这些是**模型边界**，不是待修的 bug。想查每一条的来源、假设与误差分级，看设计器读数页的
「模型精度台账」（22 条，A~D 四级；D 级明确写着"没有真机数据，只能横向比"）。

- 压气机特性图是**合成**的（设计点 + 三个常数），喘振裕度只能横向比"哪个设计更紧"。
- 设计点与额定点没有分离：打开加力会让设计点按"加力额定"重算（推力 +29%、SFC +91%）。
- 涡扇的耗油率谷底比真机偏低（真机在 85~95% 油门，本模型在低油门）。
- 外形直径按"等效捕获面积"反解，与真机机匣外径有 25% 量级的差别（预设里用 `NacelleDiameter` 校正）。
- 长度估算与真机差 ±8~10%；干重对复合材料风扇（GTF 那类）偏重。
- GTF1100 的涵道比算出 6.8，真机 12.5：本模型压不到那么小的核心通流面积。
- 齿轮箱只建模了重量、1/η 损失与惯量，**没有建模柔度（扭振）**。
- 三轴机不做转速解耦（缺压气机特性线时是欠定问题），改为逐台核对涡轮需/供。
