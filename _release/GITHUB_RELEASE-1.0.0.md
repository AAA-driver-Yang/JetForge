# JetForge 1.0.0

参数化喷气发动机：你填的是几何（级数、叶尖直径、轴怎么连、进气道长什么样），推力、油耗、转速、喘振裕度、长度与重量都是算出来的，不是你手填的性能曲线。

## 装之前

需要这三个前置模组，缺一个都进不去：

- **ModuleManager**（零件补丁）
- **Waterfall**（尾焰）
- **RocketSoundEnhancement**（声音）

游戏版本 **1.12.0 - 1.12.99**。

## 装

1. 解压这个 zip。
2. 把 `GameData/JetForge` 整个文件夹放进游戏的 `GameData/` 下。
3. 启动游戏。装完的目录应当是 `GameData/JetForge/JetForge.version` 这一层，不是 `GameData/JetForge/JetForge/...`（多套一层游戏认不到）。

## 这一版有什么

- **发动机设计器**：压气机 / 涡轮 / 燃烧室 / 喷管逐项填，气路用传递模型解，判据（温度、转速、喘振、堵塞、轴功率、重量）实时给结论。
- **独立的进气道零件**：自己的编辑面板，型线可以一段段摆位置、改宽高、让某一圈斜过来（做得出 F-15 那种斜进气口），还有锥尖位置、唇口半径、抽气比例。
- **设计向导**：给用途、设计马赫、高度、推力，生成一版初稿装到零件上。
- **齿轮传动风扇**：风扇与低压涡轮之间加齿轮箱，能做 PW1100G 那一类大涵道比齿轮传动发动机；齿轮箱的重量与一阶柔度（静扭角、本体扭振频率）一起算。
- **试车台与剖视**：整台机器在台架上跑一遍，剖视图看内部结构。
- **设计库**：存 / 读 / 改名 / 复制 / 删除，每台留五份历史，两台并排比十行读数，`UserDesigns/Shared/` 做交换站。
- **撤销**：拖滑杆松开记一步，Ctrl+Z 退二十步（详细模式与简单模式各记各的）。
- **中英双语界面**，跟随游戏语言。

## 这一版没有的

- 特性图只做读数与展示，不参与推力解算。
- 齿轮箱柔度只到一阶（齿面接触柔度、轴承游隙、行星均载、齿频激励都没建模）。
- 部分预设（F100 / F110 / CFM56）没有可靠数据源，没做。
- 第三方兼容只做了 Waterfall 与 RocketSoundEnhancement，RealSolarSystem / Ferram 没测。
