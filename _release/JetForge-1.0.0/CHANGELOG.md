# 更新日志

本文件只记"玩家能感觉到什么变了"。逐条技术细节在 `docs/phase2-mod.md`（不入发布包）。

> English: see [CHANGELOG.en.md](CHANGELOG.en.md).

## 1.0.0 — 首个可发布版本

### 新增

- **风扇齿轮变速（GTF）**：风扇页新增「减速齿轮比」（1 = 直驱，1~4 可调）与「齿轮效率」。
  齿轮让低压轴与风扇各按自己的转速转，代价是齿轮箱的重量（百公斤级）、
  1/η 的机械损失、更长的机身与更大的轴惯量（加速变慢）。
  新增预设 **GTF1100（PW1100G 级齿轮传动涡扇）**：风扇 Ø2.06 m、齿轮比 3.0、推力 ~103 kN。
- **独立进气道零件**：进气道是独立部件，有自己的编辑窗口（截面骨架 / 单截面轮廓 / 参数页）。
  可自由画截面（九种预设 + 自由多边形 + X/Y 镜像 + XY 轴对称），型线直接生成 3D 外形。
- **真激波模型**：进气道超声速恢复按正激波 / θ-β-M 斜激波 / 锥激波分级求解，
  超过该马赫的最大偏转角就判"激波脱体、未起动"，恢复按正激波算。
- **原版进气道兼容**：同船上装原版进气道也能喂 JetForge 发动机。
- **可调中心锥**：超声速下按马赫自己往前推，喉道收窄（可关）。
- **锥尖位置可调**：进气锥不再钉死在唇口后面——模板外形有「锥尖位置」滑杆（占长度的百分比，
  正数可以伸出唇口），自己画型线的那条有「锥尖前伸 m」。两处都只改外形，不改喉道面积与流量。
- **进气道面板分「设计」「读数」两页**：以前四十多行挤在一列里，改一根滑杆要往下翻一屏半才能
  看到读数。现在改的和看的分开，各一屏放得下；迎面马赫、迎角那些"不在这里设"的说明也一起搬去读数页。
- **压气机特性图**：喘振线 / 堵塞线 / 工作线 / 喘振裕度，热力图里可直接看。
- **逐轴转矩平衡**、**几何接口校核**（进出口面积对不上会报出来）、
  **故障三级台账**（设计期警告 / 运行期风险 / 实际事件，同一缺陷不重复罚）。
- **发动机测试台**（设计器读数页）：海平面静推力、不同高度/马赫/油门的工况点、SFC 曲线。
- **设计向导**：按用途（战斗机 / 运输机）、年代与飞行马赫挑一个标定预设起手，填目标推力，
  向导反解叶尖直径与风扇压比（只缩放尺寸，压比效率温度不动），并逐条说明初值来自哪儿、
  哪几条互相矛盾。改坏了能撤销（存三步）。
- **我的设计库**：调好的一台能存成文件（换飞船、重开存档都还在），列表里能载入、改名、复制、删掉。
  每次保存前自动留一份历史（最近五份，能点回去）；两台设计可以并排比十行读数——推力 / SFC /
  总压比 / 涵道比 / 涡轮前温 / 流量 / 喘振裕度 / 长度 / 干重 / 造价，它只报方向和差值，
  不替你拍总分（推力大 10% 和造价低 10% 不是同一种好）。
  **交换站**：库里的那台可以放进 `GameData/JetForge/UserDesigns/Shared` 贴给别人，
  别人放进来的文件在「分享」面板里一键收进自己的库；同名不覆盖你自己那份，会自动改名。
  文件怎么传不归模组管（论坛、网盘、聊天都行），模组只管两头。
- **拖动滑杆能撤销**：设计器底栏多了「撤销（还能退 N 步）」按钮，`Ctrl+Z` 同效，最多退二十步。
  只在手松开时记一步，退回的是拖动开始前那个数；换了零件、载入别的设计或点了「还原」之后
  不再跨机器撤销。简单模式那屏滑杆一样能退，两条撤销栈各记各的，切模式不会串。
- **中英双语**：界面、状态栏、判据说明、零件名与描述都有英文；日志保持中文（那是给开发者看的）。
  英文缺句时退回中文，不会出现半中半英的一行。
- **控制系统分档**：机械 / 液压 / 模拟 / 数字（FADEC）。差别是真实能力而不是标签——机械档不限温度、
  模拟档没有喘振抑制与超转切油、只有数字档会自动再点火。年代决定可选档，也决定喷口是不是闭环。
  **有控时节流阀是推力指令**：控制器把油量闭环找出来，指令按约两秒爬满，杆子一把拉到底推力也不会跳变；
  机械档没有推力传感器，仍是"杆位直接给油量"。
- **空中再点火窗口**：转速 12%~70%、点火器压力门槛按档次 45/35/28/20 kPa；
  出了窗口点不着，并说清差的是转速还是进气压力。
- **逐级喘振余量**：不止整机一个数，还报「第几级最紧」——前级负荷重、后级轻，可调静子会把它掰平；
  另一种常见的错是收油门时反而更靠近堵塞侧。
- **模型精度台账**：22 条模型各写清来源、假设、误差与适用边界，分 A~D 四级。
  D 级明确写着「没有真机数据，只能横向比」——**宁可知不知道，不假装知道**。
- **判据按严重度排**：最该修的那条永远在第一行；藏起来的通过项折成一行「另有 N 条通过」。

### 新增

- 进气道型线的截面能斜过来了：在俯视/侧视图里**横着拖某一颗边缘点**就能让这一圈倾斜，
  侧视改前掠、俯视改侧偏，两轴可以一起歪——能做出 F-15 那种斜着切进气流的进气口。
  倾角只改外形，不改进气量与推力；存盘向后兼容（老存档读出来是 0°）。
- 型线编辑器：**第一个截面拖不动**（画布跟着它一起平移缩放，看着像原地不动），
  也不能往前伸——现在量程锚在 0 且只增不减，第一段与最后一段都是 ±2 m。
- 型线编辑器：第一个截面的**倾角点贴在画布边缘**、手一抖就点空，现在另给了一行
  「倾角：侧视/俯视 [-5°][+5°]」按钮，斜进气口不用全靠手稳。

### 修复
- **对称放置的几件进气道，供气量只按一件算**：两件各能吞 30 kg/s 的进气道喂一台要 70 的发动机，
  以前合计流量会被悄悄压回"最大的那一件"，于是面板写着供气 120、发动机却只吃到 30，
  油门推满也到不了额定推力。现在多件的流量就是各件之和，**上限只由发动机进口面决定**——
  装几件都不会白拿推力，但也不会白装。
- **镜像/同款放置的进气道，改了一件别的不跟着变**：窗口把参数抄给同型号的那几件时漏了
  「重建外形」那一步，字段与读数都变了、零件外形还是旧的，看上去就是"改了没生效"。已补上。
- **按玩家要求撤掉"过载损伤"**：拉 g 不再累积轴承应变、也不会把发动机弄断推力，
  只剩喘振、烧穿、超速三条真会毁机的路。"结构：过载损伤"与"加强系统"两个选项一起移除
  （老存档里这两个键会被忽略，重存时不再写出）。
- **独立进气道做得再大也不会让推力涨**：以前发动机吃多少空气只看零件喉道有多大，
  把进气道外形做到 Ø7 m，一台 2 t 的机器就会"吃"进七千多 kg/s、推力翻几倍（有玩家实测到
  344 kN / 7787 kg/s）。现在发动机进口那张面是硬上限：面就那么大、面马赫就那么高，
  多出来的空气只能在唇口溢流，状态栏会说"进气道做多大都不会让推力变多"。
- **「初稿好了」和「还没有可以交的初稿」同时出现在一屏上**：底栏判断"参数改过没有"用的是
  `Math.Abs(a-b) > 1e-9`，而滑杆返回的是量化到像素步长的数，喂回去每帧都算"改过"——
  初稿生成出来一帧就被自己清掉。现在判据按显示精度比（马赫 0.001 / 高度 1 m / 推力 0.05 kN），
  并且**改参数不再销毁初稿**，只说明"这份是按旧参数算的"。
- **向导的结论现在弹在屏幕中央**：生成成功/失败、装上成功/失败各弹一句（`ScreenMessages`），
  不再依赖窗口里能被滚走的那几行。**这一版要重启游戏才生效**——DLL 只在启动时载入一次。
- **点了「生成初稿」像没反应**：生成其实在跑，可结论（生成完毕、实算推力、每条初值的来路）全写在滚动区里，
  而那颗按钮本来就贴着滚动区下沿——新出来的几行正好落在视野外面。现在底栏固定一行先说结论：
  「初稿好了：风扇 Ø1.51 m｜实算 88.3 kN / 目标 90 kN」，失败就说"原因在下面滚动区里"，窗口也加高了 60 px。

- **设计向导的初稿「显示已生成，却没地方交出去」**：生成完初稿之后再点一下用途 / 技术年代 / 加力，
  初稿会被清掉，而「生成完毕」那句话还留着，底栏那颗按钮跟着一起消失。现在参数一变，
  那句话和初稿一起清；底栏那颗按钮永远在——没初稿时它灰着，并写清楚先点「生成初稿」。
  拖马赫 / 高度 / 推力滑杆也算改参数（以前拖完照样能交，交出去的却是旧参数算的那份）。
  按钮也改名了：「把初稿装到这台发动机上（同时打开设计器）」，它本来就干这两件事。

- **矢量喷管的偏航方向是反的**：俯仰一直带着负号，偏航却没有——两轴的规则其实一样
  （指令为正，力矩沿该控制轴的负向）。现在补上了，退化装机的兜底方向也跟着改。
  以前那条回归断言只钉了"偏了多少度"，没钉"往哪边偏"，方向反了照样通过。
- **设计向导的「交给设计器」按钮被挤到窗口外面**：滚动区抢光了窗口剩下的高度，底栏没地方站，
  于是屏幕上写着"初稿生成好了"却点不到那颗按钮。现在滚动区有上限，底栏常驻；点完还会回读一次
  （真换上了才说"已交给设计器"，没换上就说没换上），并顺手把设计器打开给你看。

- **右键菜单里露出一串 `#autoLOC_...`**：加力按钮的名字是"本地化键 + 状态（自动/常开）"拼起来的，
  KSP 只在整句就是一个键时才翻译，于是键原样摆到了玩家眼前。现在键先翻好再拼。
  顺带把百分号排版改成"数字紧挨着 %"（原来印成「70 %」），日志里手写在格式串里的那几处空格也去掉了。
- **「短舱直径」那一栏以前基本没用**：它被拿去撑大进气口，而外壳画在那个半径的 1.03 倍上——
  填 2.15 量出来 2.21，填得比进气口小还会被整个忽略。现在它决定外壳最粗处，填多少量多少。
- **大涵道比的风扇舱不再被捏瘪**：外涵喷口半径以前取"风扇 86%"与"核心机 1.72 倍"里的小者，
  大涵道比时后者小得多，风扇舱在四分之一机身里从 1.08 塌到 0.57。现在只保留"至少包住核心机"的下限。
- **尾部机匣不再从喷管里戳出来**：没装加力时，核心机匣会越过喷管起点多画一段、半径比喷管外壁还大，
  两个壳互相穿。现在机匣收在喷管起点上，喷管根部也从那个半径接着长；涡喷的进气口同时不再靠短舱撑大
  才盖得住压气机面，那圈卡箍也终于露在蒙皮外面了。

- **设计器「总体」页的设计库改成一行一台**：以前一行硬塞三台，名字按钮被七个按钮挤到看不清，
  现在一台一行，提示语也从按钮那一行挪到了下面。

- **ALT 复制或对称放置后整件变透明**：克隆零件与原零件共享同一份网格，重建时把别人的网格销毁了。
  现在网格延迟退役、只销毁没人引用的，关原版模型前先确认自家外形真的在。
- **同款两台发动机改一台另一台不变**：设计器「构建网格」以前绕过了正规提交路径。
  现在走 `ApplyDesign`（按设计指纹传播），并加了「同型全部跟着改」按钮处理已经分叉的存档。
- **实飞推力比面板大**：原版把油门做了 `Lerp(min,1,input)` 重映射，我们按原始油门当分母反解，
  低油门时凭空多出 18%。现在两边用同一个油门口径，往返偏差 0.00%。
- **原版进气道"小件给大流量"**：捕获面积改为"从嘴径算"与"从 cfg 面积折算"取小，
  不再重复乘缩放平方。
- **进气道竖线点不中 / 拖点乱跳 / 侧视上下反**：命中顺序改为竖线优先、视觉与命中同一宽度；
  拖动只按增量且冻结视野；侧视方向修正。
- **进气道截面"拧麻花"**：环与环的起点不一致导致放样螺旋，现在起点归一化是不变量。
- **飞行中卡顿**：摘掉飞行路径上每帧白花的开销（网格退役全场扫描、进气道指纹比对、自愈轮询）。
- **进气道迎角/侧滑一直是 0**：`PartModule` 的 `FixedUpdate` 从没被 KSP 调过（应为 `OnFixedUpdate`）。
- **改一个词就静默改行为**：设计向导里原来用界面文案分派输入框（认出「推力」两个字才按 kN 处理），
  文案一改就落到 else 分支——马赫框变成 0~25 的范围、输入 26 被夹成 25 且不报错。
  现在按参数自己的范围分派，与屏幕上写什么无关。
- **判据栏 FAIL 排在第六屏**：原来按物理顺序（温度→燃烧→喷管→轴→堵塞→级间）列，
  一条 FAIL 配七八条 WARN 时，最该修的那条要往下翻。现在按严重度排，同级保持原顺序。

### 已知限制

- 非设计点（飞行中）的风扇转速按「轴转速 / 齿轮比」走，与设计点一致（第 107 段验过：同一个设计
  只改齿轮比，风扇叶尖速度在设计点与 70% 转速下都正好是直驱的 1/3）。**齿轮箱的惯量已建模**
  （当薄环、回转半径 0.3 倍风扇半径，折到低压轴；GTF1100 上 110 kg → 4.2 kg·m²，占低压轴 0.5%，
  第 109 段验过升速按 J 的比例变慢）；**齿轮箱的柔度是一阶模型**：薄壁筒按质量反解壁厚、
  `k = G·Jp/L`、静扭角 `τ/k`、本体扭振 `√(k/J_gb)/2π`（GTF1100 上 26 kN·m 下扭 0.003°、
  本体扭振 1864 Hz，第 114 段钉住量级）。不做的是齿面接触柔度、轴承游隙、多级行星均载与
  齿频激励——它够用来说明"这个箱子在纸面上不软"，不够用来做扭振设计。
- 锥激波用等偏角斜激波加 1.25 倍损失近似（没有解析解），公开图表同偏角高 2~3 成。
- 压气机特性图是**合成**的：设计点加三个常数（喘振流量系数 0.90、堵塞 1.18、喘振压比 1.20），
  不是真机数据。所以喘振裕度只能拿来横向比"哪个设计更紧"，不能当绝对判据；台账里它是 D 级。
- 原版进气道 `area × 64` 这个折算只有一个样本对上过（CircularIntake），其它件靠量外形兜底。
- 长度估算与真机差 ±8~10%；干重估算对复合材料风扇（GTF 那类）偏重。
- GTF1100 的涵道比算出来 6.8，真机 12.5：核心机通流面积在本模型里压不到那么小。
